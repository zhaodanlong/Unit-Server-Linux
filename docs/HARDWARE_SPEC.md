# Unit-Server 硬件规格

## 核心硬件

| 组件 | 型号/规格 | 说明 |
|------|-----------|------|
| CPU | Allwinner H3 | 四核 Cortex-A7 @ 1.2GHz |
| RAM | 512MB DDR3 | - |
| 存储 | TF Card (MMC0) | 支持 SDHC/SDXC |
| WiFi/BT | RTL8723BU | USB 接口, 802.11n + BT 4.0 |

## GPIO 引脚分配

| 功能 | 引脚 | 说明 |
|------|------|------|
| KEY1 | PA19 | 用户按键 1, 低电平有效 |
| KEY2 | PA18 | 用户按键 2, 低电平有效 |
| STATUS_LED | PA10 | 状态指示灯, 高电平点亮 |
| USR_LED | PG11 | 用户指示灯, 高电平点亮 |
| LCD_DC | PA12 | LCD 数据/命令选择 |
| LCD_RES | PA11 | LCD 复位 |
| MIC | 模拟输入 | H3 内置 Codec |

## LCD 显示屏

| 参数 | 值 |
|------|-----|
| 型号 | ST7789VW |
| 分辨率 | 240x135 |
| 接口 | SPI0 |
| SPI 速度 | 50MHz |
| 旋转 | 270° |

### LCD 偏移说明

240x135 的屏幕是从 240x320 面板裁切而来，需要设置偏移：

| 旋转角度 | 列偏移 | 行偏移 |
|----------|--------|--------|
| 0° | 52 | 40 |
| 90° | 40 | 53 |
| 180° | 53 | 40 |
| 270° | 40 | 52 |

## 串口

| 接口 | 用途 | 波特率 |
|------|------|--------|
| UART0 | 调试串口 (CP2102) | 115200 |

## USB

| 接口 | 用途 |
|------|------|
| USB OTG | Type-C 供电 + 数据 |
| USB Host | WiFi 模块 (内部) |
